# Three-minute demo script

Setup: `python -m scripts.seed && python -m scripts.simulate --count 300` (or the Overview buttons), open the control panel, **Demo** page, tick "Use cached results" if offline.

1. **0:00 What it is.** "FinGuard sits between people/agents and any model the firm controls. It cannot see public apps like claude.ai; it covers the gateway, Claude Code hooks and agent tools." Show the Overview: real numbers, simulated share stated.
2. **0:30 The problem.** Demo page → Run all. Read the banner: N of 13 scenarios produced a harmful outcome without FinGuard, K with it. Say: this is a deliberately risky mock model.
3. **1:00 Three scenarios side by side** (press → in presentation mode `P`): advice + guaranteed return (rewritten, referral); card number (redacted before the model, masked evidence); agent emailing the client list (blocked, DORA third-party ref).
4. **1:45 Evidence.** Click a Live traffic row: redactions, raw vs final diff, rule trace with regulation references (illustrative), engine nemo, timings.
5. **2:15 Humans stay in charge.** Review queue: MNPI and payment approvals; approve one; Audit → Verify chain (intact), then explain it is a demonstration and the head hash must be stored elsewhere.
6. **2:40 Honesty.** Evaluation page: model named, misses listed (hard paraphrases), false-positive rate. About page: limitations.
